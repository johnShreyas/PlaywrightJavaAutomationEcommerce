# Playwright Java E2E Automation Framework

[![Playwright Tests](https://github.com/johnShreyas/PlaywrightJavaAutomationEcommerce/actions/workflows/playwright.yml/badge.svg)](https://github.com/johnShreyas/PlaywrightJavaAutomationEcommerce/actions)

An end-to-end test automation framework built with Java 21, Playwright, and TestNG, integrated with GitHub Actions CI/CD.

## Tech Stack
* **Language:** Java 21
* **Engine:** Microsoft Playwright
* **Test Runner:** TestNG
* **Build Tool:** Maven
* **CI/CD:** GitHub Actions (Ubuntu)

## Project Structure
* `src/test/java/Pages/` - Page Object Model classes
* `src/test/java/Tests/` - Test scripts and TestBase setup
* `.github/workflows/` - CI/CD pipeline configuration
